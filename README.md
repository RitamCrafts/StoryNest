# StoryNest 🚧

> Under Development

StoryNest is a clean and peaceful blogging platform designed for writers and readers to share, explore, and connect through meaningful stories.

## Current Features

- ✍️ Create and publish stories
- 📖 Explore community posts
- 🔐 User authentication
- 🖼️ Image support for posts
- 🎨 Minimal and distraction-free interface

## Upcoming Features (maybe)

- Rich text editor
- User Verification
- User profiles
- Bookmarks
- Search functionality
- Categories and tags
- Improved reading experience

## Tech Stack

- React
- Tailwind CSS
- Appwrite
- Vite

## About

StoryNest aims to make writing effortless and reading enjoyable by providing a calm space where ideas can be shared and discovered.

Built while learning and experimenting with modern web technologies.
